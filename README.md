# Push Up Pricing and Performance Analysis

This repository contains data analysis, exploratory analysis, feature correlation studies, pricing strategy evaluation, and statistical modeling for push up performance and pricing optimization.

## Project Structure

- `eda_pushup_analysis.py`  
  Exploratory data analysis

- `preprocessing_analysis.py`  
  Data cleaning and preprocessing

- `metric_correlation_analysis.py`  
  Correlation analysis between metrics

- `feature_interest_analysis.py`  
  Feature importance and interest analysis

- `pricing_strategy_analysis.py`  
  Pricing strategy evaluation

- `advanced_pushup_analysis.py`  
  Advanced analytical methods

- `robust_pushup_modeling.py`  
  Robust statistical modeling

## Dataset

The analysis uses:

`Pricing Push Ups - data.csv`
